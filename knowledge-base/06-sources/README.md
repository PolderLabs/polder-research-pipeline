# Sources

Canonical bibliography and evidence records. Every source that informs a durable note is catalogued here.

## Papers

Academic papers with citation metadata: title, authors, venue, year, DOI or URL. Includes distillation summaries and key claims extracted from each.

## Repositories

Code repositories, model weights sources, and dataset origins. Includes version pinning, licensing, and access notes.

## Documentation

Official documentation, standards documents, and specification references. Includes links and access dates.

## Evidence Records

Structured evidence entries from intake processing. Each record links a claim in a durable note to a source with an evidence classification: Observed / Source-reported / Inference.
