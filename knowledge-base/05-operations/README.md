# Operations

Experiments, benchmarks, roadmaps, and runbooks. Notes here capture operational knowledge: what was tried, what worked, and what comes next.

## Experiments

Experiment definitions, protocols, hypotheses, and results. Experiment protocols describe experimental setup. Systematic evidence-review protocols define eligibility, search, screening, extraction, appraisal, and synthesis; see [[00-home/research-methods|Research methods]]. Each experiment is a structured note covering setup, variables, observations, and conclusions.

## Benchmarks

Reproducible benchmark definitions, result schemas, and historical results. Benchmarks are versioned and include provenance for the environment they were run in.

## Roadmaps

Milestone plans, priority rankings, and resource allocation. Roadmaps capture the planned evolution of the project over time horizons.

## Runbooks

Step-by-step operational procedures: deployment, recovery, escalation. Runbooks are used under pressure; clarity and completeness matter.
