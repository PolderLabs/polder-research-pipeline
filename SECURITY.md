# Security policy

Polder Research Pipeline is Alpha software. The local dashboard has no authentication and must not be exposed beyond loopback. Do not place sensitive material in a public issue or pull request.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** feature on this repository to send a private report. Include affected versions or commits, reproduction steps, impact, and any suggested mitigation. Do not publish exploit details before a fix is available. We will acknowledge reports as soon as practical; this project does not currently provide a formal response-time SLA.

If private vulnerability reporting is unavailable in the repository's Security tab, contact the maintainers through the GitHub organization profile and ask for a private reporting channel. Do not include secrets or personal data in the request.

## Supported versions

Only the latest `main` branch is currently maintained. No release-based security support window is promised.
