# System

Architecture, performance, transports, deployment, and runtime. Notes here describe how the system is built and how it runs.

## Architecture

Component diagrams, data flows, interface contracts, and subsystem boundaries. Covers the logical and physical architecture.

## Runtime and Transports

IPC mechanisms, network protocols, data formats, and message schemas. Covers inter-process and inter-service communication.

## Performance and Latency

Benchmarks, SLAs, bottleneck analysis, and latency budgets. Covers end-to-end performance and optimization opportunities.

## Deployment

Environment definitions, configuration management, rollout strategies, and observability. Covers shipping and operating the system.
